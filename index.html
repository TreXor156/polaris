$0 Static Portal
  • 1
    Content Intake (Google Forms): Subject Matter Experts submit structured playbooks and markdown scripts via a standardized intake form—eliminating direct database edits and formatting errors.
  • 2
    Relational Database (Google Sheets): Four normalized tables (Books, Pages, Users, and User_Progress) act as a live headless CMS, queried client-side via the Google Visualization JSON API.
  • 3
    Automation & Sync API (Google Apps Script): Automates 90-day compliance review windows, enriches missing taxonomy tags using the Gemini API, and exposes serverless doGet/doPost endpoints for role-based access and cross-device progress tracking.
  • 4
    Frontend & Hosting (GitHub Pages — $0/mo): A responsive Tailwind CSS & Vanilla JS single-page application served directly from GitHub Pages, delivering instant search, markdown rendering, and Patron Card gamification with zero server costs.
Stack Cost: $0/month • Setup: Serverless
